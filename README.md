# DateDreamer Monorepo

This is the workspace for all DateDreamer packages.

## Packages

- `@datedreamer/core`: Pure logic and state engine (Headless).
- `@datedreamer/web-components`: The standard Web Component implementation.
- `@datedreamer/react`: React hooks and components.
- `@datedreamer/vue`: Vue composables and components.
- `@datedreamer/angular`: Angular wrappers.
- `@datedreamer/theme`: Design system and CSS tokens.

## Getting Started

```bash
pnpm install
pnpm build
```
